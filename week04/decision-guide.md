Week #4
S3 is best used for storing large and unstructured data for the most cost effectiveness. 
EBS is for attaching volumes to a single EC2 instance, for the EC2 to have it's own persistent storage.
EFS is a serverless storage service that is best used for sharing/common file systems. 
RDS is best used for structured data, when data needs to be organized and queried for specific retrievals.
DynamoDB is a noSQL database, which is very scalable but still has key-value storage for quick retrieval.
